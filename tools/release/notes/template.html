Dragon Ball Z: Infinite World — Native PC Port

This port uses static recompilation (MIPS R5900 → C++) and Vulkan rendering. The download contains no disc files, translated game code or compiled game. Everything needed to build the game from your own disc on your own PC is included.

What you need

  • Dragon Ball Z: Infinite World, PAL SLES-55347, as an ISO.
  • An x86-64 CPU with AVX2 and a Vulkan-compatible graphics card with current drivers.
  • Windows 10 (1903 or newer) / Windows 11, or Linux with glibc 2.31 or newer.

No separate compiler, Git or Python installation is required. The first build works offline.

Linux: AppImage

  1. Download DBZIW.AppImage.
  2. Mark it executable in your file manager, then open it.
  3. Select your ISO and click Start.
  4. Let setup verify the disc, translate the code and compile the game. Allow several minutes; the time depends on your CPU. The game starts when setup finishes.

Open the same AppImage again to play. Linux updates reuse unchanged build files where possible; your saves and settings stay in the player data folder.

Windows: ZIP

  1. Download DBZIW.windows-x64.zip and extract it to a short path such as C:\Games\DBZIW.
  2. Keep the extracted files together and launch DBZIW.exe. If SmartScreen warns about the unsigned program, choose More info → Run anyway.
  3. Select your ISO and click Start. The first start builds the game locally; later starts launch it directly.

Game data and saves

  • Windows: %LOCALAPPDATA%\DBZIW\
  • Linux: $XDG_DATA_HOME/dbziw/, normally ~/.local/share/dbziw/

Within that folder, the compiled game is in build/ and memory-card saves are in game/mc0/. Game files, settings and logs also stay there, separately from the download.
